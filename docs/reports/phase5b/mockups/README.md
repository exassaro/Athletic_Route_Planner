# Phase 5b mockups (approved 2026-11-18)

The source of the GATHO design canvas (a private claude.ai Design artifact). The `.dc.html` files are Design Component pages that render on that canvas, not app code. Every number in them comes from the API's own A01 examples in `api/athlete_api/examples/`; the map is a schematic.

- `Brand.dc.html`: wordmark, app icons (sneaker), markers, pixel icons, colour tokens with contrast, type scale, components.
- `Runner.dc.html`: the start-pin sneaker, the runner (empty state) and the approved 4-frame run cycle.
- `Light.dc.html`, `Dark.dc.html`: peek, half, full, over_budget, share page.
- `Setup.dc.html`: the five setup steps.
- `Main.dc.html`: the phone component they all import.

The exact sprite strings are in [../sprites.md](../sprites.md).
