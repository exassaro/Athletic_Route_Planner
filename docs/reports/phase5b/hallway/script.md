# Hallway test (Phase 5b, GATHO): script for the facilitator

Five runners, one at a time, about 15 minutes each, on their own phone or one you hand them, at `https://<laptop LAN address>/` (set up as in [../../phase5/phone.md](../../phase5/phone.md)). The same task as Phase 5, so the two rounds can be compared. Pass: the runner completes the task without help.

## Before each session

- On the phone, clear site data for the site (or use a private tab), so it starts at the first setup step, in the light theme, at the default pace (6:00 /km).
- Have the feedback form ready: [feedback-form.md](feedback-form.md).
- Note the start time.

## Say this, word for word

> "This is GATHO, a planner for running routes. I want to see whether it's easy to use, not test you. Please think aloud as you go. I can't help you once you start, but you can stop whenever you like."

Then hand them the task card.

## Task card (show or hand over)

> **Plan this run:**
> Start at **Athanikkal** and run **25 km** towards **Kozhikode**.
> On the way, pass **Kottakkadavu, Kadalundi, Chaliyam, the Karuvanthuruthy bridge (on the Chaliyam–Feroke road), Beypore and Kallai**.
> When you have the route: what is its distance, and in what order does it pass the six places?

## What to watch for (do not say any of this aloud)

| Step | Success looks like | Note if |
| --- | --- | --- |
| 1 Start | Types "Athanikkal" in the first question and picks the village; the setup moves on by itself | Picks a wrong Athanikkal; tries the map first |
| 2 Distance | Taps the 25 km quick pick, or types 25, then Next | Misses the quick picks; unsure the number took |
| 3 Shape | Leaves "Point to point" and taps Next | Hesitates over the three shapes |
| 4 Which way | Searches Kozhikode under "Towards a place", then Next | Skips the step (then the run has no direction); uses the compass instead |
| 5 Stops | Adds some or all places here, or skips and adds them later | Expects the bridge here (it is added after planning, from the map) |
| Plan | Taps "Plan my run"; watches the little runner while it plans | Doesn't see the button |
| Stops after planning | Taps the "stops" chip, or scrolls to Stops, then "+ Stop" and searches | Can't find where to add more stops |
| The bridge | "+ Stop", then "Pick a bridge or road on the map", taps the bridge, picks "Chaliyam - Feroke Road (this bridge)" | **The bridge is not searchable by name.** Note how long it takes. Help only after 3 minutes, and then it counts as "with help" |
| Answer | Reads 25.0 km from the peek bar or the card, and the order from the stops timeline | Reads the wrong card; can't find the order; confused by "1·2" on the map |

Also note, without prompting:
- whether they drag or tap the sheet's handle, and whether they find the half and full positions;
- whether they swipe the route cards;
- whether they notice the Undo message after an edit;
- whether they open the menu.

"Without help" means you said nothing after the task card. Give help only if they are stuck for 3 minutes on one step, and record it.

## After the task

1. Ask them to fill in the feedback form (about 3 minutes).
2. Record on the form: time taken, steps where they got stuck, help given (yes or no, which step).
3. Ask for one open answer: "What would you change first?"
4. Optional, if they have a minute: switch to Dark in the menu and ask whether the map and the route are easy to read.

## Afterwards

Put the five forms in `docs/reports/phase5b/hallway/results/` (one file per runner, no names: runner-1 to runner-5). The acceptance criterion is 5 of 5 completing without help.
