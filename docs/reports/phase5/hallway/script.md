# Hallway test: script for the facilitator

Five runners, one at a time, about 15 minutes each. Each runner uses their own phone, or a phone you hand them, on `https://<laptop LAN address>/` (set up as in [../phone.md](../phone.md)). Pass: the runner completes the task without help.

## Before each session

- On the phone, clear site data for the planner (or use a private tab) so it starts empty.
- The runner's pace is set on the page itself. Leave it at the default unless they change it.
- Have the feedback form ready: [feedback-form.md](feedback-form.md).
- Note the start time.

## Say this, word for word

> "This is a planner for running routes. I want to see whether it's easy to use, not test you. Please think aloud as you go. I can't help you once you start, but you can stop whenever you like."

Then hand them the task card.

## Task card (show or hand over)

> **Plan this run:**
> Start at **Athanikkal** and run **25 km** towards **Kozhikode**.
> On the way, pass **Kottakkadavu, Kadalundi, Chaliyam, the Karuvanthuruthy bridge (on the Chaliyam–Feroke road), Beypore and Kallai**.
> When you have the route: what is its distance, and in what order does it pass the six places?

## What to watch for (do not say any of this aloud)

| Step | Success looks like | Note if |
| --- | --- | --- |
| Start | Searches "Athanikkal", picks the village | Picks a wrong Athanikkal, or can't find the search box |
| Distance | Sets 25 km (stepper or typing) | Struggles with the stepper |
| Towards | Searches Kozhikode under "Towards" | Puts Kozhikode as a stop instead |
| Plan | Taps "Plan my run" | Doesn't notice the button |
| Stops | "+ Stop", searches each place | Confused by the picker (several Kadalundis) |
| The bridge | Finds "Pick a bridge or road on the map" and taps the bridge | **The bridge is not searchable by name.** Note how long it takes. Help is allowed only after 3 minutes, and then it counts as "with help" |
| Answer | Reads 25.0 km and the stop order from the screen | Reads the wrong card, or can't find the order |

"Without help" means you said nothing after the task card. Give help only if they are stuck for 3 minutes on one step, and record it.

## After the task

1. Ask them to fill in the feedback form (about 3 minutes).
2. Record on the form: time taken, steps where they got stuck, help given (yes or no, which step).
3. Ask for one open answer: "What would you change first?"

## Afterwards

Put the five forms in `docs/reports/phase5/hallway/results/` (one file per runner, no names: runner-1 to runner-5). The acceptance criterion is 5 of 5 completing without help.
